## プロジェクト概要

このプロジェクトは、シンプルな掲示板アプリケーションです。  
ユーザーは以下の機能を利用できます:

- 掲示板の作成
- 掲示板の編集
- 掲示板の一覧表示

Rails 7.0 を使用して構築されており、MySQLをデータベースとして利用しています。  
また、Bootstrapを使用してUIをスタイリングしています。
